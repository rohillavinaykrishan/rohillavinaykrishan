# MG1 Roster + Clash (master f0-356), v001

Self-contained HyperFrames sub-comp, 2160x3840, 25 fps, 357 frames. Scene time is the master frame (mount at data-start 0).

## Files
- `compositions/mg1.html`: the scene (`data-composition-id="mg1"`). GENERATED by `tools/build_mg1.py`; do not hand-edit.
- `index.html`: 4K root that mounts the scene (`fxScale` 1). Comp lead: mount `compositions/mg1.html` with host id `mg1`, data-start 0, duration 14.28, and copy/link `assets/mg1/`.
- `proxy/index.html`: 540x960 root (scene scaled 0.25 in a wrapper, `fxScale` 0.25). Symlinks `assets`, `compositions`.
- `mg1_proxy_540.mp4`: the proxy render.
- `spiral_handoff.json`: per-frame head positions of the 8 streaks f336-356 (r0 -> 40 px around (1080,1550), 2 turns clockwise) for MG2.
- `mg1_data.json`: the values baked in from cues.json. `inputs.json`: which plate fed each shot (color/edit/placeholder).

## Rebuild
```
python3 tools/sync_inputs.py    # plates: color > edit > placeholder; kit.js; last-frame stills R1-R8
python3 tools/build_mg1.py      # cues.json -> compositions/mg1.html, index.html, proxy/index.html
node tools/export_spirals.js    # spiral_handoff.json
cd proxy && npx hyperframes render --fps 25 -o ../mg1_proxy_540.mp4
```
## Variables (on the host's data-variable-values)
- `fxScale` (1 at 4K, 0.25 for proxy): canvas resolution of the dust, plume, fringe and streak layers.
- `spirals` (default FALSE, coordinator decision: MG2 owns the spirals and the name). MG1's streaks orbit until f335 and stop at f336, where MG2 picks them up from `spiral_handoff.json` orbit_heads_f326_336.
- `push` (default true): the whole-frame 1.00-1.04 push over f336-356 (ease.in). Turn off if the master comp pushes.

## Design decisions
- Wipes: the kit's `FX.brushMatte` geometry is captured into CSS `clip-path: path()` (incoming card = revealed rects, outgoing = frame minus revealed, evenodd), so DOM video/type and the canvas fringe/plume use the same matte. Timing is the kit's ease.out over 6 frames (producer call). Variant = k%3, seed = k+1.
- Outline names: Unbounded 900 at cap 420 px does not fit DHALSIM, E. HONDA and others in 2160. Each name is fitted to a width of 1960 px or less, with the cap height capped at 420 px. RYU and KEN get the full 420 cap; the longest names get about 230. Baseline at y 990, x 40 -> 120 linear over the slot. Overlap-free font copy `Unbounded-900-merged.ttf` (skia-pathops removeOverlaps), because text-stroke otherwise draws the inner contours.
- Tags: `01 / 08` (Bone) left and the hue name from cues.tiles (in the hue) right, Space Mono 700 34 px, y 2044.
- Shutter: slivers show band k of R(k)'s last frame; hue flash cascades 1 f apart from f223; tightens f229-236 (ease.in) into eight 6 px hue lines at y 1500, which become the streaks on f237 while the Act-2 window slams open from that bundle in 3 f.
- Streaks: orbit an inset rounded rect around the Act-2 window, at 40/55/72/92/115 px/f (one step up per cut), with 10-frame trails drawn with kit `glowStroke`. Spiral: the speed ramps linearly from 115 px/f to v_end (154-335 px/f), so the charge accelerates.
- The fg canvas uses mix-blend-mode: screen over the plates.
